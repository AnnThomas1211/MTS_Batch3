Reward Module: Eligibility & Calculation Rules Business Rules

🟢 Successful Transfer

Transaction status must be SUCCESS to qualify for point allocation.

🟢 Amount ≥ $100

Only transactions of $100 or more are eligible to earn reward points.

🟢 Peer-to-Peer

Sender and receiver must be different users (cross-user transaction).

🟢 No Self-Transfers

Transfers between accounts owned by the same user are disqualified.

Calculation Logic

1 point for every $100 transferred, rounded down (using integer division). Integrated safely inside database transactions.

points = floor(Amount / 100)
Transfer of $250.00 +2 Points
Transfer of $99.00 0 Points (Amount < 100)
Transfer of $100 (Self) 0 Points (Disqualified)

Lazy Route Mapping

Registered with dynamic lazy loading in app.routes.ts under route protection (AuthGuard).

// app.routes.ts - Lazy Loading Route
export const routes: Routes = [
  {
    path: 'rewards',
    loadComponent: () => import('./rewards.component')
      .then(m => m.RewardsComponent),
    canActivate: [AuthGuard]
  }
];
